# Modelo C4 — Oficina Mecânica

Os diagramas representam o monólito modular implementado. Não há microsserviços, mensageria ou integração externa nesta fase.

## Nível 1 — Contexto

```mermaid
flowchart LR
    cliente[Cliente]
    equipe[Equipe da oficina]
    sistema[Sistema de gestão da oficina]

    cliente -->|consulta OS e decide orçamento| sistema
    equipe -->|administra cadastros, estoque e OS| sistema
```

## Nível 2 — Contêineres

```mermaid
flowchart LR
    cliente[Cliente]
    equipe[Equipe da oficina]
    api[API NestJS\nREST + Swagger + JWT]
    banco[(PostgreSQL 17)]

    cliente -->|HTTPS/JSON + código de acompanhamento| api
    equipe -->|HTTPS/JSON + Bearer JWT| api
    api -->|Prisma ORM / transações SQL| banco
```

## Nível 3 — Componentes da API

```mermaid
flowchart LR
    http[Controllers e DTOs]
    auth[Módulo Autenticação]
    clientes[Módulo Clientes]
    veiculos[Módulo Veículos]
    servicos[Módulo Serviços]
    pecas[Módulo Peças/Insumos]
    os[Módulo Ordens de Serviço]
    acomp[Módulo Acompanhamento]
    indicadores[Módulo Indicadores]
    prisma[Módulo Banco de Dados / Prisma]
    banco[(PostgreSQL)]

    http --> auth
    http --> clientes
    http --> veiculos
    http --> servicos
    http --> pecas
    http --> os
    http --> acomp
    http --> indicadores

    os -->|identidade e propriedade| clientes
    os -->|veículo| veiculos
    os -->|preços e composição| servicos
    os -->|saldo e baixa atômica| pecas
    acomp -->|consulta e decisão| os
    indicadores -->|datas e composição| os

    clientes --> prisma
    veiculos --> prisma
    servicos --> prisma
    pecas --> prisma
    os --> prisma
    acomp --> prisma
    indicadores --> prisma
    prisma --> banco
```

## Mapeamento para o código

| Elemento | Implementação |
|---|---|
| Composição principal | `src/aplicacao.module.ts` |
| Interface HTTP | `src/modulos/*/apresentacao/` |
| Casos de uso e portas | `src/modulos/*/aplicacao/` |
| Modelo e regras | `src/modulos/*/dominio/` |
| Adaptadores | `src/modulos/*/infraestrutura/` |
| Persistência | `prisma/schema.prisma` e `src/banco-dados/` |
| Execução local | `Dockerfile` e `docker-compose.yml` |
