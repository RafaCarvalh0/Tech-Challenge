# Análise de vulnerabilidades - 2026-10-27

## Comandos executados

```bash
npm audit --omit=dev
npm explain prisma
npm explain multer
npm explain js-yaml
```

## Resultado

- As vulnerabilidades transitivas de `multer` e `js-yaml` foram corrigidas por overrides para `multer@2.5.0` e `js-yaml@5.5.0`.
- Permanecem 4 apontamentos de severidade alta em `deepmerge-ts` e `effect`.
- A origem dos apontamentos restantes é o pacote `prisma`, declarado como dependência de desenvolvimento para migrations e geração do cliente.
- A correção automática exige atualização principal do Prisma 6 para o Prisma 7, alteração incompatível que requer migração específica do ORM.

## Decisão

O upgrade do Prisma será tratado em incremento próprio. O CLI não é importado pelo código da API em execução, mas os apontamentos permanecem registrados e não devem ser considerados resolvidos.

Não utilizar `npm audit fix --force` sem validar a migração do Prisma e executar novamente build, testes unitários, cobertura e testes E2E.
